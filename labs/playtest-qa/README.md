# Playtest / QA lab

Automated: deterministic sim tests, bot balance reports, browser smoke test, screenshot review (see `balance-qa-engineer`).
Human (required): the owner plays and answers the **playtest checklist** per game. Automated checks cannot establish that a game is fun.

## Standard owner checklist (5 minutes)
1. In your first 2 minutes, did you know what to do and why?
2. After 3 runs, can you describe one build that felt different from another?
3. Did you want a 4th run? If not, what made you stop?
4. Anything confusing, broken, or ugly?
5. Would you show this to a friend? Would you pay $3 for it? (Honest answer — "no" is useful.)
