# Market research lab

Purpose: replace [claimed] with [verified] before money or build time is spent.

**Method (per question):** state the question and what result would change the decision → find the primary source (listing, policy page, store page) → record figure, link, retrieval date, and tag → write the verdict. If a source blocks automated access, mark "could not verify" and, if it matters, hand the owner a 5-minute manual check.

- `backlog.md` — ranked opportunities with scorecard math
- `verification-queue.md` — the specific claims to check, in priority order
- `briefs/` — one short evidence-tagged brief per question
